    Connect and install

    1. Plug the board in with a USB data cable and click Connect device.
    2. Pick the serial port, then choose Install DFU32.
    3. Enter your WiFi network name and password, then click Visit device to open DFU32’s own web UI and claim it.

    This version needs an erase.

    No board chosen: fine for a device already running DFU32. A new install needs a board.
    About “Erase device”

    ESP Web Tools may offer it. Erasing removes the saved WiFi, the API token and the configured target. Updating without erasing keeps them. Only erase for a clean start.

    Installing needs a desktop browser

    The installer talks to the board over Web Serial, which works in Chrome, Edge and Firefox (151 or later) on a desktop or laptop. Open this page there with the board plugged in.

    Or flash it yourself

    Download the image for your board and flash it with esptool. It’s a full image, so it resets saved settings. The README has the command.

    Already installed? Connect without choosing a board: DFU32 tells the page which board it is, so you can update it, change WiFi or open its page. Settings are kept unless you erase.

    Stage a repeater image over USB

    No artifact server needed: the page can put an nRF52 DFU package (the .zip from adafruit-nrfutil, such as a MeshCore release asset) straight into DFU32’s staging partition. Click Connect device, then choose Stage nRF52 image and pick the zip. The page checks it the way DFU32 does, writes it over USB and restarts DFU32; WiFi, the token and the target are kept. Then flash the repeater from DFU32’s page with Flash from: staged image.

    Pick the right zip. An image staged this way isn’t labelled with a board, so DFU32 can’t tell if it was built for your repeater. Staging resets the ESP32, so don’t do it while DFU32 is flashing a repeater.

    Troubleshooting
    No serial port listed
    Use a USB data cable; charge-only cables don’t show up. On the Feather ESP32 V2, install the CP210x or CH9102 driver.
    ESP32-S3 not detected
    Hold BOOT, tap RESET, then release BOOT and click Connect device again.
    RAK11200 doesn’t start flashing
    It has no auto-reset circuit. Pull BOOT0 to GND, press RESET, then click Connect device and Install DFU32. Afterwards, release BOOT0 and press RESET again.
    “Your ESP32 board is not supported”
    No board is chosen and the device didn’t report one (it isn’t running DFU32 yet, or runs a release from before boards were reported), so the page doesn’t know which image to install. Close the dialog, choose your board above and connect again. With a custom build, it means the build is for another board than the connected DFU32 reports (the page says which under the version list), or for another chip.
    WiFi failed
    DFU32 joins 2.4 GHz WPA2-Personal and open networks (WPA2/WPA3 mixed works, WPA3-only doesn’t). Check the password and retry.
    No “Stage nRF52 image” option
    It appears only when the connected device runs DFU32 and answers over Improv. Install or update DFU32 first, then connect again.
    Can’t reach the device afterwards
    Try http://dfu32-xxxx.local from a computer on the same network.
