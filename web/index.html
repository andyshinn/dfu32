    Install

    1. Connect the board with a USB data cable and click Install.
    2. Pick the serial port, and it flashes (about a minute).
    3. Enter your WiFi network name and password, then click Visit device to open DFU32’s own web UI and claim it.

    About “Erase device”

    ESP Web Tools may offer it. Erasing removes the saved WiFi, the API token and the configured target. Updating without erasing keeps them. Only erase for a clean start.

    Installing needs a desktop browser

    The installer talks to the board over Web Serial, which works in Chrome, Edge and Firefox (151 or later) on a desktop or laptop. Open this page there with the board plugged in.

    Or flash it yourself

    Download the image for your board and flash it with esptool. It’s a full image, so it resets saved settings. The README has the command.

    Troubleshooting
    No serial port listed
    Use a USB data cable; charge-only cables don’t show up. On the Feather ESP32 V2, install the CP210x or CH9102 driver.
    ESP32-S3 not detected
    Hold BOOT, tap RESET, then release BOOT and click Install again.
    RAK11200 doesn’t start flashing
    It has no auto-reset circuit. Pull BOOT0 to GND, press RESET, then click Install. Afterwards, release BOOT0 and press RESET again.
    WiFi failed
    DFU32 joins 2.4 GHz networks only. Check the password and retry.
    Can’t reach the device afterwards
    Try http://dfu32-xxxx.local from a computer on the same network.
